BHAI DOOJ WEBSITE FOR RIYA

1. Unzip this folder.
2. Add your sister's photo to the images folder and name it riya.jpg.
3. Open index.html in a browser.
4. To publish it, upload the whole folder to a static host such as GitHub Pages or Netlify.

Files:
- index.html: first page, Diwali greeting and Bhai Dooj note
- page2.html: large photo and closing note
- style.css: all styling and mobile layout
- script.js: carousel controls and auto-advance

The carousel uses online Unsplash image URLs, so those images need an internet connection.
You can edit the text directly in the HTML files.
